# عروض قطر — Qatar Deals (PWA)

نسخة ويب قابلة للتثبيت كتطبيق (Progressive Web App) بكل الميزات الاحترافية.

## الميزات المطبّقة
- **مقارنة نفس المتجر عبر التطبيقات** — يظهر أرخص تطبيق لنفس الطلب (ماكدونالدز/كنتاكي كمثال) مع مقدار التوفير.
- **طبقة الثقة** — كل عرض عليه "تم التحقق قبل …" + لون مؤشّر الحداثة + زر إبلاغ عن العروض المنتهية.
- **تحليلات السوق** — لوحة ذكاء تسعير (متوسط الخصم بالقسم، توزيع العروض بالتطبيق، أعلى المتاجر خصمًا) كمنتج B2B.
- **عروض اليوم + مشاركة واتساب** — يولّد أقوى 5 عروض كرسالة جاهزة للنشر اليومي.
- **PWA** — قابل للتثبيت على الموبايل/سطح المكتب ويعمل أوفلاين بعد أول فتح.
- مفضلة، إضافة عروض من التجار، باقات اشتراك، وضع ليلي/نهاري، عربي RTL.

## التشغيل والنشر (مهم للـPWA)
الـPWA لازم يُفتح من رابط https (مش ملف محلي) عشان التثبيت والأوفلاين يشتغلوا.

1. ارفع **كل محتويات هذا المجلد** (index.html, manifest.json, sw.js, الأيقونات) على استضافة:
   - الأسهل: افتح `app.netlify.com/drop` واسحب **المجلد كامل**.
   - أو Vercel / GitHub Pages / Cloudflare Pages.
2. افتح الرابط الناتج على موبايلك.
3. **التثبيت**: على أندرويد/كروم يظهر زر "تثبيت" في الأعلى. على آيفون (Safari): زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

> ملاحظة: فتح `index.html` مباشرة بالنقر المزدوج يشغّل التطبيق للمعاينة، لكن ميزتَي التثبيت والأوفلاين تحتاجان استضافة https.
